V2.0 TEMPLATE-GUARD

修复场景：
- 两个客户使用同一种交友软件资料页模板
- 都是白底/灰底 + 粉红渐变圆形头像框 + HeyID + 固定 UI
- 旧版局部特征可能只匹配到公共模板，给出 85~89.99% 疑似撞客

新逻辑：
1. 判断是否为资料页/模板页。
2. 自动找主要圆形头像区域。
3. 可靠圆形区域使用饱和度连通域优先，避免 Hough 被文字/圆角 UI 干扰。
4. 忽略共享的外圆边界，重点比较圆形头像内部高频结构。
5. 如果页面模板相同但头像内部明显不同，直接压到疑似阈值以下，不提示撞客。
6. 同一头像的压缩/缩放/镜像不会被该规则错误否决。

保留 V1.9.9 全部功能。
