V1.9.1 GitHub + Railway 部署

1. 解压 ZIP，把全部内容上传到 GitHub 仓库根目录。
2. Railway 连接该 GitHub 仓库。
3. Variables：
   BOT_TOKEN=你的Token
   DATA_DIR=/data
4. 给 worker 添加 Volume，Mount Path：/data
5. 保持 1 Replica。
6. 部署。

成功启动日志应包含：
TG防撞客机器人 V1.9.1 SAFE-MATCH SSCD-AI COPY-GUARD AUTO90 GitHub + Railway 启动
SSCD 同图识别 AI 模型加载成功

首次启动可能先下载约 99MB SSCD 模型，后续模型保存在 /data/models。

升级旧数据库无需重新导入客户。V1.9 会自动迁移 SQLite 表结构，并后台补建 SSCD AI 索引。
群里 /aistatus 查看进度。

重要：V1.9 在 Railway 上要求持久化 Volume。如果 Volume 未挂载，会直接停止启动，这是为了防止数据库临时丢失后把老客户全部误判为新客户。
